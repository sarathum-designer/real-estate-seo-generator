# Real Estate SEO Content Generator

**Live:** https://raghav-seo.vercel.app

An AI tool that writes SEO-optimised copy for real estate listings and project pages, with a built-in paraphrasing mode that produces distinct variants for each page or portal.

## Features

- Generates titles, meta descriptions and body copy for property listings
- Paraphrases text so content isn't duplicated across pages and portals
- Runs in the browser with no install

## Tech

HTML · CSS · JavaScript · LLM API · Vercel

## Run locally

Open `index_with_paraphrasing.html` in a browser.
